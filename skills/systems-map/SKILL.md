# Systems map

Jesse, Oct 28: "We're quite small… quite top heavy and system heavy." "We just have to start just turning shit off."

## Inputs
- `vault/_shared/tool-map.md`
- What Jesse and Mike say; bank or card statements only if Jesse shares them

## Steps
- [ ] For each tool, fill what's UNKNOWN by asking one question at a time: what it's for, who logs in, what it connects to, what it costs a month.
- [ ] Mark each: **keep**, **simplify** (name the clunky steps), or **cut candidate** (name what would replace it).
- [ ] Never cancel anything. A cut is Jesse's or Mike's to do; draft the steps for them.
- [ ] Write the table back to `tool-map.md` and one line in today's daily note.

## Output
The updated tool map and a three-line summary: total monthly cost known so far, the top simplification, the top cut candidate.

## Done means
Every tool has an owner, a purpose and a verdict, or an UNKNOWN with the question that resolves it.

## Never
- Cancel, downgrade or sign up for anything.
- Recommend leaving Ascora without the measured cost of staying (see `projects/ascora-simplify/SPEC.md`).
