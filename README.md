# Smart Contracting AIOS

Smart Contracting's AI operating system: one Claude Code chat, the **Chief of Staff**, that runs the business for Jesse and Mike. It installs itself, keeps its memory in an Obsidian vault, maps out and builds what comes next on Jesse's yes, and reaches their existing Revenue Partner (Hermes on Orgo) directly.
